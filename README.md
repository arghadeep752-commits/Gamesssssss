# Zombie Strike

A 3D first-person zombie shooter for Android, made with Unity 2021.3 LTS and built entirely in the cloud with GitHub Actions — no PC needed.

## Get the APK

Every push to this branch builds a new APK and publishes it on the repository's **Releases** page as `zombie-strike-build-<number>`. Open it on your Android phone and tap the `.apk` file to install.

## One-time setup

Unity needs a (free) Unity Personal license to build. Add two repository secrets under **Settings → Secrets and variables → Actions**:

| Secret | Value |
| --- | --- |
| `UNITY_EMAIL` | your Unity account email |
| `UNITY_PASSWORD` | your Unity account password |

Two-step verification must be turned off on that Unity account (a separate free Unity account just for building works well).

## Controls

- **Left side**: move (floating joystick — push all the way to sprint)
- **Right side**: drag to look around
- **Fire button**: hold to shoot; drag while holding to aim
- **Reload button**: reload; the pause button is top-right

## Project layout

- `Assets/Scripts` – the game (the level, player, weapon, zombies, waves and UI are all generated by code)
- `Assets/Editor/BuildScript.cs` – creates the scene and materials, sets the Android options and builds the APK
- `Assets/Resources` – textures and sounds (generated by `tools/gen_assets.py`)
- `.github/workflows/zombie-strike.yml` – the cloud build
