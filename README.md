<h1 align="center">DevDarshan · देवदर्शन</h1>

<p align="center">Hindu devotional wallpapers for Android: a user app, an admin app and a Firebase backend.</p>

---

## What is in this repository

| Path | What it is |
| --- | --- |
| `apps/user` | **DevDarshan** (`com.devdarshan.wallpapers`), the public wallpaper app. |
| `apps/admin` | **DevDarshan Admin** (`com.devdarshan.admin`), a separate APK for uploading and managing content. |
| `packages/native` | Kotlin native module (Expo Modules API): set wallpaper (home / lock / both), save to the gallery, share (including straight to WhatsApp), Google sign-in through Credential Manager, plus a config plugin for release signing, R8 and ABI splits. |
| `packages/ui` | Shared React Native UI kit: theme, typography, icons, buttons, sheets, toasts, skeletons and empty/error states. |
| `packages/shared` | Platform-neutral code used by both apps **and** the Cloud Functions: types, constants, search keywords, validation, theme tokens and legal text. |
| `firebase/` | Firestore and Storage security rules, Firestore indexes, Cloud Functions (image processing, counters, admin roles, safe deletes, cleanup) and the rules tests. |
| `scripts/ci` | Build helpers used by GitHub Actions: Firebase app registration, signing, APK verification and the emulator smoke test. |
| `scripts/setup` | `gcp-setup.sh`, a one-time Google Cloud Shell script that connects GitHub Actions to the Firebase project without keys. |
| `docs/` | Setup, architecture, data model, security, build/release, testing, admin guide and privacy policy. |

## Highlights

- **Real wallpaper setting.** Uses Android's `WallpaperManager` with `FLAG_SYSTEM` and `FLAG_LOCK` applied separately, and reports per-screen results honestly: if only the home screen changed, the app says so.
- **Downloads that respect Android storage rules.** Uses MediaStore on Android 10 and later (no storage permission at all), and the legacy path with a permission capped at Android 9 on older phones. Files go to `Pictures/DevDarshan`.
- **Sharing.** Uses a `FileProvider` content URI with a direct WhatsApp target when WhatsApp is installed. It never claims a share succeeded just because the share sheet opened.
- **Genuine Google sign-in** (Credential Manager, then Firebase Auth). Favourites sync and update optimistically.
- **Server-side image pipeline.** Uploads are validated, auto-oriented and size-capped, with WebP previews, thumbnails, blur-up placeholders and dominant colours generated by Cloud Functions (sharp). Clients never write image URLs or counters.
- **Admin access is enforced by the backend.** It requires a custom claim *and* a role document, both writable only by Cloud Functions. The first admin is bootstrapped from a server-side setting, and nobody can grant themselves access.
- **Fast and offline-tolerant.** Paged queries, recycled lists (FlashList), cached thumbnails and the Firestore offline cache.
- **Lightweight.** Per-phone APKs (arm64 / armv7), compressed native libraries and JS bundle, R8 shrinking, English + Hindi resources only, and no analytics, ads or unused SDKs.

## Getting it running

You don't need a computer. The whole pipeline runs in GitHub Actions in this repository:

1. Follow **[docs/SETUP-FROM-PHONE.md](docs/SETUP-FROM-PHONE.md)** once. This covers creating the Firebase project, the Blaze plan, Google sign-in, the Storage bucket and the Cloud Shell script.
2. Fill in `config/firebase-project.json` and push.
3. GitHub Actions deploys the backend, builds both signed APKs, verifies them, runs them on an Android emulator and publishes them as a **[GitHub Release](https://github.com/arghadeep752-commits/Gamesssssss/releases)**. Anyone can download from there on a phone.
4. Install **DevDarshan Admin**, sign in with the bootstrap admin account and tap **Claim admin access**. Then add the starter categories and upload wallpapers.

Before step 2, every push still builds **test APKs** (placeholder config, marked `-TEST`) so the code is always proven to compile and launch.

## Tech stack

React Native 0.86 on Expo SDK 57 (Continuous Native Generation, New Architecture, Hermes), TypeScript, React Navigation 7, TanStack Query 5, FlashList 2, expo-image, zustand, React Native Firebase (Auth, Firestore, Functions, Storage), Kotlin (Expo Modules API, Credential Manager), and Cloud Functions v2 on Node 22 (firebase-admin, sharp).
