# DevDarshan demo content

Original abstract artwork (mandalas, diyas, lotus, Om, trishul, peacock feather,
temples…) generated by `scripts/demo/generate-demo-content.mjs` on the `main`
branch. It is used only by **demo builds** of the DevDarshan app, which are made
while no Firebase project is connected. Real builds show wallpapers uploaded by
DevDarshan admins.

Layout: `wallpapers/<id>/original.jpg`, `preview.webp` (≤1440×2560), `thumb.webp` (≤540×1200).
